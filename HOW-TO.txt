INSTEAD OF SLEEPING: HOW THIS SITE WORKS
=======================================

WHAT IS IN THIS FOLDER
  index.html     the page itself (site name and footer line are in here)
  style.css      colors, fonts and layout
  site.js        the part that reads your writing and builds the pages
  about.txt      the text of the About page
  writing/       your pieces, one text file each
  writing/list.txt   the list of pieces to show

PUTTING IT ONLINE
  Upload this whole folder, as it is, to any web host that serves plain
  files. Open the address the host gives you. Nothing needs installing.

  Note: double-clicking index.html on your own computer shows a message
  instead of your writing. Browsers block a page from reading nearby files
  unless it comes from a web host. This is normal.

ADDING A PIECE
  1. Make a text file in the writing folder, e.g. my-new-poem.txt
     (lowercase letters, numbers and dashes; no spaces).
  2. Start it like this, then a blank line, then your writing:

       Title: The name of the piece
       Date: 2026-11-10
       Category: Poems

     Optional extra line: "Label: Sonnet" for a finer description.

  3. Add the file name on its own line in writing/list.txt.
  4. Upload the new file and list.txt.

  The read time is worked out from the word count (200 words a minute).
  The newest piece by Date appears in the purple block on the home page.

CATEGORIES
  Whatever you put after "Category:" becomes a section, shown across the
  top of the home page with a count. Spell it the same way every time.
  There is no separate list of categories to maintain: use a new name and
  it appears; stop using one and it goes away.

REMOVING A PIECE
  Delete its line from writing/list.txt (and the file, if you like).

FORMATTING INSIDE A PIECE
  blank line          new paragraph
  line break          kept as written (good for poems)
  *words*             italics
  **words**           bold
  # A heading         small heading (on its own, with blank lines around it)

CHANGING THE NAME OR COLORS
  Site name and footer line: open index.html and look for "CHANGE ME".
  Colors: the list at the top of style.css.
